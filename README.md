# ジョーバ（johba）

スマホブラウザ向け・騎手視点3D競馬ゲーム。

プレイヤーは騎手としてレースに騎乗し、ゲートインからゴールまでを馬上後方カメラで操作します。鞭のタイミング、位置取り、スタミナ配分、馬場と天気の相性、他馬との駆け引きで1着を目指す、リアル志向のレースゲームです。

## 遊び方

1. タイトルからスタートすると、レース条件（距離・天気・馬場）が発表される
2. 出走表で12頭のスペックを確認し、乗りたい馬を3頭選んで申請する
3. 抽選で騎乗馬が決まる（各1/3）。決定後は非公開ステータス（気性・調子・ゲート）も開示される
4. 発走の合図に合わせてタップしてスタート
5. レース中の操作
   - 右下「▲」：仕掛ける（ペースを上げる。スタミナ消費増）
   - 左下「▼」：抑える（温存・掛かり解消）
   - 画面中央を左右スワイプ、または左右端タップ：進路変更
   - 鞭ボタン：数秒間の強い加速（スタミナ大量消費・連打は効果減衰）
6. ゴール後、着順発表 → 結果画面（着順・タイム・スコア・講評）
