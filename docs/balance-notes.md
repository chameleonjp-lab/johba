# バランス調整ノート

単位：速度 m/s、距離 m、時間 s、スタミナは 0〜1000 の内部値。

| パラメータ | 現在値 | 意味 |
|---|---|---|
| straightLen | 450 | 直線の長さ（×2本） |
| turnRadius | 120 | コーナーの柵（ラチ）基準半径 |
| laneWidth | 2.0 | 1レーンの幅 |
| laneCount | 12 | レーン数（0=最内） |
| 周長 | 約1654 | 2×450 + 2π×120。柵基準で距離を測る |

## 調整目標（ヘッドレス検証で確認する）

- 良馬場で勝ち馬のタイムが基準タイム±1.5s に収まる
- 1着→12着のタイム差が 1.5〜4s 程度
- 同条件10回で勝ち馬が5頭以上に散り、ペース表記（ハイ/ミドル/スロー）も変動する
- 無操作（巡航まかせ）のプレイヤーは概ね中団〜後方。好騎乗で上位を狙える
