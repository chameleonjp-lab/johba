# バランス調整ノート

`index.html` 先頭の `CONFIG` 定数ブロックと対応する。値を変えたら必ずここの「現在値」と「履歴」を更新する。
検証は `node tools/sim-harness.mjs [回数] [距離|random] [シード] [馬場|random]` で行う。

単位：速度 m/s、距離 m、時間 s、スタミナは 0〜1000 の内部値。

## コース

| パラメータ | 現在値 | 意味 |
|---|---|---|
| STRAIGHT_LEN | 450 | 直線の長さ（×2本） |
| INSIDE_RADIUS | 120 | コーナーの柵（ラチ）基準半径 |
| LANE_WIDTH | 2.0 | 1レーンの幅 |
| LANE_COUNT | 12 | レーン数（0=最内） |
| 周長 LAP_LEN | 約1654 | 2×450 + 2π×120 |
| GOAL_S | 430 | ゴール板のコース固定位置（ホームストレッチ上）。スタート位置は (GOAL_S−距離) mod 周長 |
| CORNER_PENALTY | 0.008 | コーナー中の前進効率 = 1 − レーン×0.008（外を回すロス） |
| START_NEUTRAL_DIST | 300 | 発走直後この距離はコーナーロス無効（1600/2400のコーナー発走の枠順不公平を防ぐ） |

備考：4距離すべてを直線発走にできる周回ジオメトリは存在しない（スタート位置が400m間隔の等差列になるため必ずどこかがコーナーに乗る）。実競馬同様コーナー発走を許容し、中立区間で公平性を担保する。

## AI（脚質別の目標速度）

| 脚質 | 序盤（〜min(500m, 25%)） | 道中 | スパート開始（残り） |
|---|---|---|---|
| 逃げ | 先頭を取るまで巡航+0.9、取れたら+0.15。他の逃げ馬が近いと+0.35（ハナ争い→ハイペース） | 巡航+0.12×個体差 | 400〜550m |
| 先行 | 巡航+0.35×個体差 | 巡航 | 550〜750m |
| 差し | 巡航−0.15 | 巡航×0.99 | 650〜850m |
| 追込 | 巡航−0.3 | 巡航×0.975 | 480〜680m |

- スパート中は目標 maxSpeed+1（実際の上限は末脚ボーナス込み effectiveMax）
- スタミナ20%未満かつスパート前は巡航−0.45へ自重
- 個体差 ai_aggr＝0.85〜1.15（毎レース抽選）
- 詰まったら進路変更（スパート中は外優先・道中は内優先）。空いていれば内ラチへ寄せる

## ペース表記

先頭馬の「15%→50%地点の区間平均速度 ÷ 出走馬の巡航平均」で判定（発走加速の影響を除外）。
PACE_HIGH: 1.031超でハイ / PACE_SLOW: 1.021未満でスロー（実測レンジ0.998〜1.040の三分位）。

## 基準タイム（スコア用）

| 距離 | 良 | 稍重 | 重 | 不良 |
|---|---|---|---|---|
| 1200 | 70.5 | 71.2 | 72.3 | 73.3 |
| 1600 | 92.5 | 93.4 | 94.8 | 96.2 |
| 2000 | 116.5 | 117.7 | 119.4 | 121.2 |
| 2400 | 142.0 | 143.4 | 145.6 | 147.7 |

算出：良＝（実測勝ちタイム平均＋0.7s、0.5刻み丸め）。稍重/重/不良＝良×1.010 / ×1.025 / ×1.040（0.1刻み丸め）。

実測の良馬場勝ちタイム平均（フェーズ3・AI鞭導入後）：1200≈69.6 / 1600≈91.9 / 2000≈115.6 / 2400≈141.5（各 seed 7/1/99/13・12レース平均。基準より0.5〜0.9s速い＝タイムボーナスが現実的に狙える設定）。AI鞭で終盤350mが加速したぶん、フェーズ1比でおおむね+0.2〜0.5s速くなったため基準を上方修正。

## スコア

着順基礎点：1000 / 600 / 400 / 250 / 150 / 100 / 80 / 60 / 40 / 25 / 15 / 10。
タイムボーナス：基準タイムより速い0.1秒ごとに+5点（上限300点）。

## 調整目標（ヘッドレス検証で確認する）

- 良馬場で勝ちタイムが基準タイム−2s〜±0s に収まる ✅
- 1着→12着のタイム差が 4〜8s 程度（実競馬よりやや広め＝ゲームとしての見栄え優先）✅
- 同条件10回で勝ちゼッケンが5枠以上に散る ✅（7〜10/10）
- ペース表記がハイ/ミドル/スローいずれも出る ✅
- 掛かり発生レースが2〜6/10程度 ✅（フェーズ3：1200=5 1600=6 2000=3 2400=5）
- 勝ち脚質が先行に寄りすぎない（差し・逃げが勝ち、追込も稀に勝つ）🔶（フェーズ3：先行が最多だが各距離で75%以下に収まる。1600で先行9/12=75%が上限ケース。30ランダムで逃げ6/先行21/差し3。追込の勝ちは稀）
- 1着→12着差は2400で8sを超える（フェーズ3：平均9.4s/最大12.7s）🔶。後方馬は残スタミナ5〜12%で完走しており、BATE_SPEED_FLOORを0.91へ上げても着差は不変（床は残スタミナ0時のみ作用）。差はスピード能力差（勝ち馬sp84〜90 vs 後方sp40〜48）＋距離適性ペナルティに由来する構造的なもの。長距離の見栄え優先として許容
