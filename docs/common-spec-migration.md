## ジョーバの既存効果音と今回の補修

音色と基準ゲインは維持。ホームに音量スライダーを追加し `johba_volume` に0〜1を保存する。未設定は1×既存SND_MASTER、既存 `johba_sound=off` は維持。0を未設定扱いにしない。AudioContext初期化はユーザー操作時のみ、オフ操作を先に反映し、音失敗でゲームを止めない。ストレージ読取例外もゲーム起動を止めない。
